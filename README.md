# FocusPath 🎯
**Organized, distraction-free learning videos — from YouTube to job-ready.**

Built for **wHACKiest 2026** · Track 4: **UnlockED** (bridging learning and employment)

## The problem
Students learn job skills from YouTube, but:
- Good videos are **scattered** — no clear order of what to watch
- **Distractions** (Shorts, recommendations, comments, autoplay) pull them away
- They waste time and don't finish the skills companies need

## Our solution
FocusPath organizes the best videos on a specific topic into one clean page:
- 📚 **Topic-wise collections, in the right order** (e.g. Web Development → HTML → CSS → JavaScript)
- 🎬 **Distraction-free player** — only the chosen video: no Shorts, no recommendations, no comments, no autoplay
- ✅ **Progress tracking** — mark videos as done and see how far you've come

## Planned features
- 🔊 AI voice recap of each topic using **ElevenLabs**
- ☁️ Hosting and saved progress on **AWS** (Amplify + DynamoDB)

## Tech stack
HTML · CSS · JavaScript · YouTube embeds · ElevenLabs (planned) · AWS (planned)
